# A slug without its articles names the same page

Date: 2026-09-27. Scope: `scripts/compile_memory.py::_with_snapshot_actions`.

## What happened

The C-6 measurement (24 real drafts on a copy of the vault,
`2026-09-27-the-compile-keeps-the-pages-it-shows.md`) found, in both runs of the
current rule, a proposed new page whose slug differed from an existing page's slug
only by the word "the" (shape: `the-x-y` beside an existing `x-y`). The snapshot
turned a create into an update only on an exact slug match, so the draft would have
added a near-duplicate page.

## Measured on the live vault (read-only, 212 pages, 197 in canonical slug form)

Existing slug pairs that one normalization would merge:

- drop the articles `the`, `a`, `an`: 0 pairs;
- drop articles and common function words (of, and, to, in, for, on, is, with, by,
  at, its): 0 pairs — but it would also treat "x-in-y" and "x-of-y" as one page;
- articles plus a trailing plural `s`: 1 pair — two existing pages that are
  themselves a singular/plural duplicate (left for the owner's review, not merged);
- articles plus word order: 0 pairs.

The 15 pages with title-case file names do not collide with any canonical slug
after kebab-casing.

## Sources

- Yoast, "What is a slug": "The slug that's generated by default may include function
  words like "a", "the", "and", "of", and "to". Sometimes, you might need those to
  clarify what your page is about. Usually, however, you can leave them out."
  https://yoast.com/slug/
- Google Search Central, consolidate duplicate URLs: a canonical URL is
  "representative of the content on the page", and consolidating "helps search
  engines to be able to consolidate the signals they have for the individual URLs
  (such as links to them) into a single, preferred URL."
  https://developers.google.com/search/docs/crawling-indexing/consolidate-duplicate-urls
- Wikipedia, Record linkage: "Most, if not all, record linkage strategies would result
  in more accurate linkage if these values were first normalized or standardized into
  a consistent format." The same article shows the other side: a standardisation
  rule that is too weak misses matches, and one too strong merges distinct records.
  https://en.wikipedia.org/wiki/Record_linkage

## Decision

The narrowest key that catches the observed duplicate and merges nothing on the live
vault: a slug with the words `the`, `a`, `an` removed. A drafted slug whose key equals
exactly one existing page's key (and is not that page's own slug) is renamed to that
page before the snapshot decides the action, so it becomes an update; the retired-page
rule then applies to the page it names (rule 12). Two existing pages sharing a key is
ambiguous: the draft keeps its slug and the compile says so. A rename that would
collide with another operation of the same plan is not made, since two operations on
one path refuse the whole plan.

Rejected: function words (merges pages whose meaning the preposition carries), plural
folding (already merges an existing pair, so it would guess), asking the model again
(costs a draft and it does not see most slugs).

## Guard

`tests/test_a_slug_without_its_articles_names_the_same_page.py` fails on the old code:
a drafted `the-x-y` create beside an existing `x-y` stayed a create of a new page.

## Follow-up: a regular plural, and the live page before its retired duplicate (2026-09-27)

The live vault already held one near-duplicate the article rule could not see:
`accuracy-denominators-answers-vs-questions` (2026-09-07) and
`accuracy-denominator-answers-vs-questions` (2026-09-11), the same concept. Measured
again read-only on the live vault (212 slugs): articles plus a regular plural `s`
(not `ss`, `us`, `is`) join exactly that pair and no other; function words stay out
because they would join `x-in-y` with `x-of-y`. The later page was marked
`status: superseded` with `superseded_by` the earlier one through a recoverable
transaction (rule 12), and the vault log records it.

The key map now puts live pages before retired ones: when a key names a live page and
its retired duplicate, a draft reaches the live page; when it names only a retired
page, the draft is still refused as history, as before.
